{{/* The standing page with this title, or nil. The whole content model hangs off page titles (Home, Notice, Classes, Subscribe, each course page…). Matching by title rather than slug is deliberate: titles are what you type in Micro.blog, while slugs go through urlize, which mangles punctuation ("Fun & Games" -> "fun--games"). Only undated regular pages with a file behind them count, so a blog post that happens to be called "Classes" can never take over the class schedule, and a category's own _index.md never stands in for its course page. Usage: {{ with partial "page-by-title.html" "Notice" }}{{ .Content }}{{ end }} */}} {{- $want := partial "norm-title.html" . -}} {{- $found := false -}} {{- range site.Pages -}} {{- if and (not $found) .IsPage .File .Date.IsZero (eq (partial "norm-title.html" .Title) $want) -}} {{- $found = . -}} {{- end -}} {{- end -}} {{- return $found -}}
